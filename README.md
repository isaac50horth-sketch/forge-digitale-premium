# Forge Digitale Premium

Site de vente de formations digitales professionnelles sur l'IA et la construction de revenus en boucle.

## Déploiement

Ce projet est configuré pour un export statique Next.js, prêt pour Netlify.

## Paiements

Les liens de paiement Stripe doivent être remplacés par les vrais Payment Links une fois créés dans le dashboard Stripe.
